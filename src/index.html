Kaderplaner

Dein Kickbase-Kader auf dem Handy — Kontostand, Marktwerte und Verkaufsentscheidungen auf einen Blick.

So bekommst du den Token
  1. play.kickbase.com/freibier im Handy- oder Desktop-Browser öffnen und einloggen.
  2. Am Desktop: F12 → Tab „Application" (Chrome) bzw. „Storage" (Firefox) → Local Storage → https://play.kickbase.com → Eintrag kb.t.
  3. Den Wert (beginnt mit eyJ...) komplett kopieren — nicht abtippen, das erzeugt Tippfehler.
  4. Hier oben einfügen und auf „Verbinden" tippen.
  1. Der Token läuft nach ein paar Tagen automatisch ab — dann einfach die Schritte wiederholen und neu einfügen.

Der Token bleibt nur auf diesem Gerät gespeichert (lokal im Browser) und wird direkt an die Kickbase-API geschickt — sonst nirgendwohin.
